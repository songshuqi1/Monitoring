# 3D 监控（第一阶段）

在「监控画布」顶部选择 **3D**。2D 与 3D 属于同一个项目，使用现有变量、实时缓存、趋势、报警和通信资源，不新增采集连接。

## 开始使用

1. 从左侧组件库点击或拖入设备，按项目实际工艺搭建场景。
   「工业组件库」和「场景设备」标题可分别折叠；鼠标停留在组件上会显示可旋转的真实 3D 模型预览。
2. 选中设备，在右侧设置组件名称、编号、位置、旋转和缩放；名称会立即同步到设备树和画布标签。也可以拖动场景中的三轴手柄。位置以米、旋转以度为单位。
3. 在「共用数据绑定」选择已有的运行、数值和故障变量。储罐数值按配置量程显示液位。
4. 如需沿用某个 2D 组件的绑定，选择「跟随 2D 组件」。储罐跟随该组件的数值变量，其他组件跟随运行变量。
5. 点击「保存」，将 2D 布局和 3D 场景一并保存。未命名项目会打开创建项目对话框。
6. 点击画布内的「应用模式」，全屏只显示 3D 场景和实时标签，工具栏及左、右、下侧面板均隐藏。按 `Esc` 返回编辑，按 `F2` 切换至 2D 应用画面。

运行值大于 0 表示运行；故障值非 0 表示故障。缺少变量、质量异常或数据过期会明确提示，运行和液位动画不会使用伪造数据。默认过期时间为 15 秒，可按实际采集周期调整。

## 操作

- 左键旋转视角，按住滚轮（鼠标中键）或右键拖动平移，滚动滚轮缩放；在设备名称标签上按住滚轮也可平移。
- 场景设置中的「设备名称统一字号」调整所有设备名称；选中设备后可单独设置「名称字号」，也可恢复使用场景统一字号。字号范围为 8–48 px，随项目和 JSON 一起保存。
- 双击设备树、画布中的设备模型或设备名称标签，以及点击设备属性中的「定位到设备」，均可选中并聚焦设备。「总览 / 俯视 / 正视 / 侧视」使用约 0.85 秒的缓入缓出镜头动画，操作鼠标可随时中断过渡。
- 「移动 / 旋转 / 缩放」控制三轴手柄；吸附步长分别为 0.5 米、15 度、0.1 倍。
- `Ctrl+S` 保存项目；`Ctrl+C` 复制选中设备；`Ctrl+V` 粘贴；`Ctrl+Z` 撤销上一步；`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做；`Ctrl+D` 快速复制；`Delete` 删除；`Esc` 取消选择。输入框获得焦点时不会触发这些画布快捷键。
- 锁定设备后无法通过三轴手柄或数值框更改其空间变换。2D 和 3D 使用独立的撤销历史，切换项目时清空历史。
- 场景设置提供浅色 / 深色、网格、标签和流畅 / 标准 / 精细三种渲染质量。
- 选中设备后可查看共用趋势。点击报警记录会定位到绑定该报警变量的设备；未关联的报警会给出提示。
- 下侧「设备状态」使用自动换行的响应式卡片网格，只需上下滚动；故障、离线、数据过期及缺少变量的设备会优先排列，便于值班人员先处理异常。
- 2D 右侧属性栏、3D 左右侧栏及下侧数据栏均可拖动分隔条调整尺寸，并记住设置；3D 会随拖动按动画帧同步画布尺寸，避免临时拉伸或压缩，窗口边界会为画布保留可操作区域。
- 项目、保存及 JSON 导入导出按钮位于 3D 中间画布内的工具栏。参数下发仍从平台顶部的共用页面进入。
- 3D 工具栏沿用 2D 画布的小按钮样式并配有用途图标；画布视角工具、状态图例、操作提示和下侧数据栏均使用更清晰的大字号。
- 界面、标签和图表文字统一采用英文 Times New Roman、中文宋体。

## JSON 与项目

**3D 场景 JSON**：画布工具栏的「导出 3D JSON」保存内置模型参数、设备绑定、材质颜色、主题及相机视角。模型由参数生成，不依赖外部图片、网络模型或浏览器缓存。

「导入 3D JSON」先显示组件数量和待绑定数量，再替换当前 3D 场景；操作可撤销，不影响 2D 布局。独立导出时会把跟随 2D 组件的绑定解析为当前变量引用。

**完整项目 JSON**：在「项目」中使用「导出当前画布」或项目卡片的「导出」。格式升级为 `monitoring-platform-project` 版本 2，原有 `project.layout.widgets`、`connections` 保留，新增 `project.layout.scene3d`；旧版 2D 项目和既有 SCADA/X6 导入继续支持。

新导出的文件携带变量身份参考。导入时校验变量编号、名称、协议、通信资源、数据类型、OPC UA 节点及作用域；不匹配的引用标为待绑定，不自动创建或修改通信资源。旧版文件缺少身份参考，保留原有导入行为。

项目和编辑草稿当前保存在此浏览器本地。切换项目会保存当前草稿，并恢复目标项目草稿；正式项目文件仍通过「保存」更新。重要修改后请保存项目或导出 JSON。多台电脑同步项目需要后续增加服务端存储。

## 当前范围

内置 8 类参数化模型：储罐、水泵、阀门、电机、风机、直管、厂房框架、设备平台。单场景上限 1000 个组件；实际流畅度取决于电脑、屏幕分辨率及模型数量，应在目标工控机验证。

当前不包含外部 GLB/glTF 导入、自动三维管网布线、2D 自动生成 3D、服务端模型库。这些属于后续阶段。浏览器需要支持 WebGL 2；初始化失败时可以返回 2D 继续监控。

## 验证

- `cd frontend; node --test tests/scene3d.test.js`
- `npm.cmd run build -- --outDir .verify-dist`
- 浏览器测试采用隔离数据，需先在 `frontend/.qa` 安装 Playwright，再运行 `node tests/scene3d.browser.mjs`。该脚本使用系统 Edge，无需登录真实系统，也不接触控制器。

前端正式构建使用 `npm.cmd run build`。当前后端优先读取工作区的 `frontend/dist`；若将运行程序单独拷贝到其他电脑，需要重新嵌入前端资源并打包运行程序。
